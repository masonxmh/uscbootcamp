# Excel Homework: Kickstart My Chart

This project analyzes a dataset of 4,000 Kickstarter campaigns to identify trends in campaign outcomes, funding performance, categories, sub-categories, launch dates, and goal amounts.

## Background

Kickstarter campaigns succeed when they meet or exceed their initial funding goals. This assignment uses historical campaign data to explore which factors are associated with successful, failed, canceled, and live campaigns.

## Files

- `StarterBook.xlsx` - completed Excel workbook with formulas, conditional formatting, pivot tables, and charts.
- `Answers.docx` - written report answering the assignment analysis questions.
- `HW guideline/README.md` - original homework instructions used as the project guideline.

## Completed Analysis

The workbook includes:

- Conditional formatting for campaign states.
- A `Percent Funded` column showing funding progress toward each campaign goal.
- A three-color scale for percent funded values.
- An `Average Donation` column showing average contribution per backer.
- Split `Category` and `Sub-Category` columns.
- Pivot tables and stacked column charts for outcomes by category and sub-category.
- Converted launch and deadline dates from Unix timestamps.
- A pivot table and line chart showing outcomes based on launch date.
- Bonus goal-range analysis using `COUNTIFS()` with success, failure, and cancellation percentages.

## Report Questions

The written report addresses:

1. Three conclusions drawn from the Kickstarter data.
2. Limitations of the dataset.
3. Additional tables or graphs that could support further analysis.

## How To Review

1. Open `StarterBook.xlsx` in Microsoft Excel.
2. Review the completed worksheet formulas, formatting, pivot tables, and charts.
3. Open `Answers.docx` to review the written analysis.
