# Pandas Homework: Pandas, Pandas, Pandas

This folder contains Pandas-based data analysis challenges completed in Jupyter Notebook. The assignment offers two challenge options, and this directory includes work for both Heroes of Pymoli and PyCitySchools.

## Background

The homework focuses on using Python, Pandas, and Jupyter Notebook to load CSV datasets, create DataFrames, aggregate records, calculate summary statistics, format output tables, and identify observable trends.

## Files

- `HeroesOfPymoli/HeroesOfPymoli_starter.ipynb` - notebook analyzing fantasy game purchasing data.
- `HeroesOfPymoli/Resources/purchase_data.csv` - source purchase dataset for Heroes of Pymoli.
- `PyCitySchools/PyCitySchools_starter.ipynb` - notebook analyzing school district performance data.
- `PyCitySchools/Resources/schools_complete.csv` - source school-level dataset.
- `PyCitySchools/Resources/students_complete.csv` - source student-level dataset.
- `HW guideline/README.md` - original homework instructions used as the project guideline.

## Heroes Of Pymoli

The Heroes of Pymoli notebook analyzes player and purchase data for an optional-item fantasy game. It includes:

- Player count.
- Total purchasing analysis.
- Gender demographics.
- Purchasing analysis by gender.
- Age demographics and age-based purchasing analysis.
- Top spenders.
- Most popular items.
- Most profitable items.

## PyCitySchools

The PyCitySchools notebook analyzes district-wide standardized test results. It includes:

- District summary.
- School summary.
- Top and bottom performing schools.
- Math scores by grade.
- Reading scores by grade.
- Scores by school spending.
- Scores by school size.
- Scores by school type.

## How To Review

1. Open either notebook in Jupyter Notebook, JupyterLab, VS Code, or another notebook viewer.
2. Run cells from top to bottom if you want to regenerate the DataFrames.
3. Review the rendered tables and written observations in each notebook.

## Notes

- The notebooks use relative paths to their local `Resources` folders.
- Run each notebook from its own challenge folder so the CSV paths resolve correctly.
- Jupyter checkpoint folders and Python cache files are ignored by `04-pandas/.gitignore`.
